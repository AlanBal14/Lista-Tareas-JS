# 📝 Lista de Tareas JS

Aplicación web para administrar tareas, desarrollada con **HTML, CSS y JavaScript**.

El proyecto permite crear y organizar tareas de una manera sencilla, incluyendo diferentes funciones para mejorar la experiencia del usuario.

## 🌐 Demo

Puedes probar la aplicación aquí:

https://alanbal14.github.io/Lista-Tareas-JS/

## ✨ Funciones implementadas

- ✅ Agregar nuevas tareas.
- ✏️ Editar el texto de una tarea existente.
- 🗑️ Eliminar tareas con una animación.
- ✔️ Marcar tareas como completadas o pendientes.
- 📅 Agregar una fecha límite.
- ⚠️ Mostrar tareas próximas a vencer.
- ⛔ Identificar tareas vencidas.
- 🗂️ Clasificar tareas por categorías:
  - Trabajo
  - Personal
  - Escuela
  - Otro
- 🔍 Filtrar tareas por estado y categoría.
- 🌙 Cambiar entre modo claro y modo oscuro.
- 💾 Guardar las tareas usando LocalStorage.
